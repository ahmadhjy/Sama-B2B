# Client portal artwork

These three emblems were supplied by Sama Tours in its WhatsApp image album on
3 October 2026 at 3:10 PM, with permission to use them on the login page.
They were captured from the displayed artwork because WhatsApp's download
controls were unavailable through the connected browser. These are cropped
client emblems, not AI-generated replacements. The page renders the portal
names as accessible text below each emblem.

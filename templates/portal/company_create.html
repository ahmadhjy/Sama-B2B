How the link works

  1. Enter the client code from Sama Accounting. The company name is matched automatically.
  2. Create their shared login here, or connect their existing login using its current password.
  3. The owner signs in with the client code, completes their profile and passport copy, then invites their team.

An existing password is never overwritten here. Password resets and disabling the main company login in accounting continue to apply to HelloSama.

For a new customer, create their client record in accounting first. You can then create their portal login from either dashboard.
